# templates — modelos reaproveitáveis entre os quatro produtos

Cada pasta aqui dentro é um modelo pronto para copiar para dentro de um projeto (Skale Insights,
Skale CRM, Skale Finance Personal ou Skale Finance Business) quando ele precisar da mesma coisa.

| Modelo | Para quê | Situação |
|---|---|---|
| [backup-supabase/](backup-supabase/) | Rotina diária de backup do banco Supabase para o Cloudflare R2 — dump criptografado, verificação semanal, passo a passo de restauração | Pronto, mas ainda **não aplicado** em nenhum projeto — ver seção 9 e 13 do [README.md](../README.md) da raiz |
